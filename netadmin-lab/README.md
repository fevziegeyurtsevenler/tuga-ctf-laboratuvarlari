# 🌐 AeroTech: Ağ Teşhis Portalı (Siber Güvenlik CTF Labı)

Bu repo, **TÜGA Siber Güvenlik Komitesi** proje çalışmaları kapsamında geliştirilmiş, konteynerize bir web güvenlik labıdır.

## 🚀 Hızlı Kurulum

```bash
sudo docker-compose up --build -d
```

Erişim adresi: `http://localhost:5000`

Kapatmak için:
```bash
sudo docker-compose down
```
